# Governance

Wolfbone is maintained by Atmai as an open-source project. Atmai's maintainers
are responsible for the repository's direction, reviews, merges, and releases.

## Participation and decisions

Anyone with repository access can propose an improvement, ask a question, or
challenge a claim through an issue or pull request. When the repository is
public, these contribution paths will be open to the wider community.

Maintainers aim to explain significant decisions where the proposal is being
discussed, including the reasoning and unresolved questions. Agreement is
preferred; maintainers make the final merge and release decisions when a choice
is needed.

A proposal should be assessed through its reasoning, evidence, and usefulness.
Contributors need not use formal notation to take part. Text, diagrams, examples,
and counterexamples are all welcome ways to develop or examine an idea.

## Scope of responsibility

Maintainers distinguish proposed, implemented, and verified work in project
communications. Accepting a contribution does not certify every claim it
references. Sources, assumptions, and the scope of checks should remain visible.

Atmai's stewardship concerns the project and its contributions. Imported work
retains its attribution and applicable licence terms.

## Changing this process

Propose governance changes through a pull request to this file. Explain the
problem the change addresses so contributors can discuss it before a maintainer
decides whether to adopt it.
