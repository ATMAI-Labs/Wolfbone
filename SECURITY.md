# Security

Wolfbone is at the founding design stage. It has no released application or supported software versions yet. Repository tooling and future prototypes can still have security issues.

## Reporting a vulnerability

A monitored private reporting contact must be published here before public launch. While the repository is private, collaborators should contact Atmai's project maintainers through an established private channel.

GitHub private vulnerability reporting will be enabled and checked as part of the [public launch checklist](docs/PUBLIC_LAUNCH.md). Its availability is not currently promised.

Please do not post vulnerability details, credentials, private data, or exploit instructions in public issues or discussions. A useful private report includes:

- the affected file, revision, or component;
- the impact and conditions needed to reproduce the issue;
- a minimal reproduction using synthetic or non-sensitive data;
- any suggested correction.

Atmai's maintainers will assess reports and coordinate fixes and disclosure with reporters. There is currently no response-time commitment or bounty programme.

## Mathematical corrections

Incorrect definitions, examples, proofs, or preservation claims can be raised through the [mathematical correction issue form](https://github.com/ATMAI-Labs/Wolfbone/issues/new?template=mathematical-correction.yml), unless the report also exposes a security issue or sensitive information.
